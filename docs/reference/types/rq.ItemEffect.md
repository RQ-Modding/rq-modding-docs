# rq.ItemEffect

One of an item's effects: the game's own code and amount.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `kind` | `integer` | The game's effect code (`機能`), such as 20 for HP percent. |
| `value` | `integer` | The amount. |

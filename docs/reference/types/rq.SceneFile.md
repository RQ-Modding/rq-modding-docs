# rq.SceneFile

A scene file from `rq.scene.file`. Pass it to `rq.scene.play`, `once` or `start`, or call it with a
scene's `s` in a scene that plays already.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `path` | `string` | The file's path in the mod's folder. |
| `mod` | `string` | The id of the mod it plays as. |

[`rq.scene.file`](../api/rq.scene.md#rqscenefile), [`rq.scene.once`](../api/rq.scene.md#rqsceneonce), [`rq.scene.play`](../api/rq.scene.md#rqsceneplay), [`rq.scene.start`](../api/rq.scene.md#rqscenestart)

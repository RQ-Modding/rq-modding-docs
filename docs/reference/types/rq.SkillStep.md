# rq.SkillStep

`since 2.48.0`

A step for `rq.chara.learnable`'s `after`: a skill set to a level.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `skill` | `integer` | The skill number. |
| `n` | `integer` | The level to set, as `rq.SkillLevel.n`; 0 erases the skill. |

## Used by

[`rq.chara.learnable`](../api/rq.chara.md#rqcharalearnable)

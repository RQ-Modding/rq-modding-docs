# rq.CharaSkillGrant

A skill a character gets, in `rq.CharaFields.skills` and `rq.CharaEdit.learn`.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `id` | `integer` | The skill number. |
| `n` *(optional)* | `integer` | The rank for a rank skill, or the uses for a use skill. Default 1. |

[`rq.CharaEdit`](rq.CharaEdit.md), [`rq.CharaFields`](rq.CharaFields.md)

Options for `rq.chara.recruit`.

| Name | Type | Description |
| --- | --- | --- |
| `state` *(optional)* | `integer` | Where the character goes (`登録状態`): 1 party, 2 reserve, 4 second string. |
| `party` *(optional)* | `integer` | A party slot (`ＰＴＡ登録`) to put the character in at once. |

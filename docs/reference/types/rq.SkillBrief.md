# rq.SkillBrief

A skill as `rq.units()` lists it.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `id` | `integer` | The skill number. |
| `name` | `string` | The skill's name. |
| `rank` *(optional)* | `integer` | Its rank; only in `learned` and `potential`. |
| `cost` *(optional)* | `integer` | Its skill-point cost; only in `learned` and `potential`. |

## Used by

[`rq.Unit`](rq.Unit.md)

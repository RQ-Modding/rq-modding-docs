# rq.MusicMoment

`since 2.27.0`

A moment a pack names on its Config page, with a switch the player turns on and off.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `key` | `string` | The moment's key, as `rq.music.enabled` takes it. |
| `name` *(optional)* | `string` | Its text on the page. Default the key. |
| `tip` *(optional)* | `string` | A tip on its row. |

## Used by

[`rq.MusicListOpts`](rq.MusicListOpts.md), [`rq.MusicPageOpts`](rq.MusicPageOpts.md)

# rq.RevealOpts

Options for `rq.battle.reveal_weakness`.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `effect` *(optional)* | `boolean` | false shows the marks without the game's Weakness Search effect and blinking. Default true. |
| `log` *(optional)* | `string` | A line for the battle log, added as the reveal plays. |

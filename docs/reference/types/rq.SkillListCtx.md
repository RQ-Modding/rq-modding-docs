# rq.SkillListCtx

What `rq.skilllist.on_page` gets.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `dir` | `integer` | -1 previous, +1 next, 0 asks for the current page. |
| `page` | `integer` | The current page, from 1. |
| `pages` | `integer` | How many pages, at least 1. |

# rq.UiBox

A row or column for `rq.uikit.row` and `col`.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `gap` *(optional)* | `integer` | Pixels between widgets. |
| `pad` *(optional)* | `integer` | Pixels inside the box's edge. |
| `align` *(optional)* | `"start"\|"center"\|"end"` | Across the box: up and down in a row (needs `h`), left and right in a column (needs `w`). |

## Used by

[`rq.uikit.col`](../api/rq.uikit.md#rquikitcol), [`rq.uikit.row`](../api/rq.uikit.md#rquikitrow)

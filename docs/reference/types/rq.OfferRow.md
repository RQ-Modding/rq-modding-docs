# rq.OfferRow

A row of the skill buy list, from `rq.chara.offers`.

## Fields

| Name | Type | Description |
| --- | --- | --- |
| `index` | `integer` | The row's index, as `rq.chara.set_offer` takes it. |
| `skill` | `integer` | The skill number. |
| `points` | `integer` | The price in skill points (`取得可能スキルポイント`). |

# Roadmap

What is planned or wanted for RQ MOD and its API. Nothing here has a date. When an item ships, it
moves to the [Changelog](changelog.md).

## Planned

- **The first public release.** The engine's release zip on GitHub, with a short install note, each
  mod in its own repository with its own release zip, the mod template as a template repository,
  and this site online.
- **More names.** `rq.ids` (1.15.0) names characters, classes, items, quests, skills and states.
  1.16.0 adds monsters, races, character types, elements, item kinds and skill targets, 2.4.0
  music tracks, and 2.24.0 map kinds. Still to come: map layouts (many layouts carry several areas'
  names, so a quest and an area are the stable key), and, when the API takes their numbers, traps,
  chest contents, directions and battle results.
- **A mod template.** A repository to start a mod from: `mod.json` with its schema, `init.lua`,
  editor settings for `rq.lua`, a README, a changelog, a license, and a workflow that zips a release.
- **One page of docs in the release.** The API reference as one HTML file inside the release zip, for
  reading offline.

## Wanted in the API

### Next

In order of priority: what the mods that exist today would use, and what a new mod would reach for
first, so that a simple change never needs the game's code (`rq.ain`).

| Area | What |
| --- | --- |
| Screens | Since 2.20.1 `rq.ui` lists the footer on every screen that shows it, Rance Castle as the screen `castle` with its rooms, and the town tabs on Quests; since 2.31.0 the Party screen's 2nd Army box (its characters, their STATUS buttons and the places a dragged character is dropped on). When a mod asks: names for Trivia, CG mode, Music mode and the castle's bonus rooms, the castle's rooms as data in `rq.ui.get`, and the item card of `rq.scene.item` as a screen (today the screen under it is listed). |
| New content | In three steps, each built from the game's own pieces so none waits for new 3D. New monsters wearing a game monster's model, with enemy groups of a mod's own for random fights (in a mod's quests and the game's), their capture and their drops, came in 2.40.0 ([Monsters and enemy groups](guide/monsters.md)). Quests of a mod's own with no map (story, menu, arena) in the quest list, with their script in Lua, came in 2.41.0 ([Quests of your own](guide/new-quests.md)), and their dungeons, built from the game's tilesets and stock rooms on its 4 by 4 grid, in 2.42.0 ([A quest with a map](guide/new-quests.md#a-quest-with-a-map)). Later, in the ongoing 3D project (see [Tools](#tools)): rooms of a mod's own, new 3D models and warps off the grid. |

## Tools

- **Animations from your own art.** A tool that builds the game's animation files (`.aff`) from a PNG
  sequence and checks a Flash file against what the engine can play. Unpacking the game's own came in
  2.25.0: `rqmod-ctl flashdump` saves a file's pictures.
- **A browser for the game's files.** Came with 2.43.0: [RQ Browser](guide/file-browser.md) shows the
  game's CGs, Flash files, music, sounds, 3D textures and the names of `rq.ids` with their pictures,
  gives the Lua line that replaces or plays each, and saves them. Later: a Flash file's motion
  played, the pictures and music the installed mods put in place, the game's text, and Escape to
  close a dropdown.
- **3D models in Blender (ongoing).** Worked on over time, each step with a guide
  for people new to 3D: the game's models and animations shown in the browser and exported to glTF for
  Blender; a mod's own textures on the game's models; a mod's own models and animations, read from the
  mod's `.glb` and checked against what the engine can draw; rooms of a mod's own; fight backgrounds
  and effects.

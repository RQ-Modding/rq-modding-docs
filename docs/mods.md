# Mods

Each mod here was checked, at the version shown: we read it, ran it in the game and checked that its
zip is the one its author published.

**To install a mod:** [install RQ MOD](download.md) first, download the mod's zip, extract it into
the game's `mods` folder (so you get `mods\<the mod>\mod.json`), and start the game again. To remove
it, delete its folder. Mods that leave things in your save say so on their card.
